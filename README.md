## 📌 Overview

Finding parking wastes time and fuel. This project uses AI to support parking management, with a web interface where images can be uploaded and processed by the trained model.

## 📂 Repository structure

```
AI_Enabled_Car_Parking_System/
├── Data/            # dataset used for training
├── ModelBuilding/   # model training code
├── flask/uploads/   # upload folder used by the web app
└── flask.zip        # packaged Flask application
```

## ▶️ Run it

1. Clone the repo and unzip flask.zip.
2. Install dependencies: pip install flask plus the ML libraries used in ModelBuilding/.
3. Start the Flask app from inside the unzipped flask folder (for example: python app.py).
4. Open http://127.0.0.1:5000 in your browser.
